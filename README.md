# Studyflow Sage Planner

Actúa como un Product Manager, UX Designer y Desarrollador Full Stack experto en aplicaciones educativas.

Crea una aplicación web llamada StudyAI Planner.

Objetivo:

Ayudar a estudiantes universitarios a optimizar su tiempo mediante inteligencia artificial.

Problema:

Los estudiantes tienen dificultades para organizar tareas, proyectos y exámenes, lo que genera retrasos, estrés y menor productividad académica.

Usuarios:

Estudiantes universitarios de entre 18 y 25 años.

Funcionalidades principales:

- Registro de tareas académicas.

- Fecha límite para cada tarea.

- Nivel de dificultad (baja, media, alta).

- Horas disponibles por día.

- Priorización automática de tareas.

- Generación de cronograma semanal.

- Dashboard con estadísticas.

- Porcentaje de avance de tareas.

- Calendario interactivo.

- Recordatorios de actividades pendientes.

Diseño:

- Moderno, animado y juvenil.

- Colores verde, morado, naranja y blanco.

- Diseño responsive.

- Interfaz intuitiva para estudiantes.

- Iconografía académica divertida.

Crear las siguientes pantallas:

1. Inicio

2. Dashboard principal

3. Registro de tareas

4. Calendario

5. Estadísticas de productividad

Agregar una sección llamada:

"Cómo la IA optimiza tu tiempo"

donde se explique cómo se generan las recomendaciones.

Generar una interfaz profesional lista para ser desplegada en Netlify.
